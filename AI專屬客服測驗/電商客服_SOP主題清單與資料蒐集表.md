# 電商客服 SOP 主題清單與資料蒐集表

用途：向每家公司蒐集訓練所需資料。每個主題由企業填入官方文件、負責人和適用範圍；缺資料的主題先標記「待確認」，不要讓 AI 自動編出政策。

| 主題 | 需向企業取得的資料 | 可產生的測驗 | 優先度 |
|---|---|---|---|
| 身分核對與個資 | 核身步驟、可揭露欄位、資料遮蔽與例外 | 查單前核身、第三人查詢 | 高 |
| 訂單查詢 | 訂單狀態定義、查詢系統、客服權限 | 查不到訂單、跨通路訂單 | 高 |
| 付款 | 支付方式、授權／請款／待付款定義、異常窗口 | 有單未扣款、付款失敗、重複扣款 | 高 |
| 修改／取消 | 可修改截止點、倉儲同步、價差與退款流程 | 改址、改數量、已出貨取消 | 高 |
| 出貨與物流 | 出貨時效、物流商、追蹤、超商取貨、遺失件流程 | 無追蹤碼、配送停滯、顯示送達未收到 | 高 |
| 退貨與換貨 | 商品分類、期限、運費、商品狀態、驗收與換貨價差 | 一般退貨、拆封、瑕疵、尺寸換貨 | 高 |
| 退款 | 權限、核准節點、退款方式、狀態與通知 | 部分退款、退款中、款項未入帳 | 高 |
| 缺貨與預購 | 庫存來源、補貨、預購批次、分批出貨 | 已付款缺貨、預購延期 | 中 |
| 活動與折扣 | 活動條款、效期、排除品、疊加規則、補用規則 | 折扣碼失效、結帳價格爭議 | 中 |
| 發票 | 發票種類、開立、更正、退貨折讓、財務窗口 | 統編錯誤、退貨後發票處理 | 中 |
| 客訴與補償 | 升級條件、補償授權、回覆時限、交接 | 情緒激動、高額求償、多次轉接 | 高 |
| 風險訂單 | 風險標記、覆核權責、放行與取消規則 | 疑似盜刷、催促出貨 | 中 |

## 蒐集時的檔案清單

1. 現行官網 FAQ、退換貨／運送／隱私與活動頁面。
2. 內部 SOP、宏回覆與客服話術，含版本和核准人。
3. 客服系統截圖或操作手冊；先遮蔽帳號、密碼及真實顧客資料。
4. 已去識別化的優秀、失誤與例外案件，各主題至少數件。
5. 主管既有評分表、實習通過標準、常見錯誤與升級清單。
6. 各平台與物流商的實際合約或商家操作規則；若為台灣商家，另請法遵或財務確認法規與發票流程。

## 來源狀態標籤

每份資料標記 `公開平台說明`、`公司已核准政策`、`法規／主管機關資料`、`待確認資料`。只有「公司已核准政策」及經企業法遵確認的法規解讀，才能成為正式測驗中的公司專屬標準答案。

台灣網購解除權可參考[消費者保護法第 19 條](https://law.moj.gov.tw/LawClass/LawAll.aspx?pcode=J0170001)及[合理例外情事適用準則](https://cpc.ey.gov.tw/Upload/RelFile/2022/732504/dab37c8d-df9d-4fe1-ad73-4ef34bbf8a64.pdf)。電子發票退貨或折讓可參考[財政部說明](https://www.etax.nat.gov.tw/etwmain/tax-info/understanding/tax-q-and-a/national/business-tax/invoice/NELbx22)。
